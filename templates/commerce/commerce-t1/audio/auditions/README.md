# Écoute comparative — Produit vedette

Quatre copies du film de 30 s pour comparer les quatre pistes que le propriétaire a déjà choisies. Le mix, lui, attend son écoute. Le titre, l’artiste, le lien officiel et l’empreinte du MP3 sont dans `sources.json`. L’adresse publique de chaque MP3 a été retrouvée à partir des métadonnées de sa fiche ; le runner télécharge uniquement le fichier officiel depuis `cdn.pixabay.com`, vérifie son empreinte et le supprime après usage. Aucun original musical autonome dans Git ni dans l’artefact.

Chaque édition est un extrait à vitesse native. Le flux vidéo n’est pas réencodé. Les quatre utilisent la même voix française de la démonstration, sans nouvelle synthèse : débit 1×, quatre scènes. Niveau du lit musical ajusté avant le mix, atténuation automatique −3 / −10 dB, anticipation 120 ms, remontée 450 ms, master voisin de −16 LUFS. `controle-mixes.json` contient les valeurs réellement mesurées sur chaque sortie AAC et le digest du flux vidéo. Artefact CI : sous-dossier `ecoutes/` ; le fichier silencieux reste à la racine. Pas de Release ni d’intégration automatique dans l’application. Licence musicale Pixabay ; les quatre fiches signalaient Content ID.
